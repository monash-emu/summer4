# summer4 0.2.0a1

**Tag:** `v0.2.0a1` · **Date:** 2026-09-18 · **Status:** alpha

First pinnable release after the flows stack landed on `main` (WP12).

## Install

Prefer the latest tag ({doc}`v0.2.0a2`) unless you must pin this release:

```toml
[pypi-dependencies]
summer4 = { git = "https://github.com/monash-emu/summer4.git", tag = "v0.2.0a1", extras = ["calibration", "pandas", "frames"] }
```

## What it shipped

- Compartment taxonomy (`Property`, `Trait`, `PropertyMap`, stratification)
- Flows (`FlowModel`, `CompiledModel`, named transition / entry / exit flows)
- Results (`SavePlan`, `Result`, `Trace`, targets)
- Diffrax solver backend with save groups
- Epidemiology (`ForceOfInfection`, `MixingMatrix`) and time-varying rates
- Honest packaging: JAX / jaxlib / diffrax / equinox as core dependencies;
  `frames` extra for polars and pyarrow

## Known follow-up (fixed in 0.2.0a2)

Repeated `CompiledModel.run()` with the same save plan did **not** hit the
equinox JIT cache. Upgrade to {doc}`v0.2.0a2` for that fix.
