# summer4 0.2.0a2

**Tag:** `v0.2.0a2` · **Date:** 2026-09-20 · **Status:** alpha

This release is about **repeated solves staying compiled**. Everything else
below is useful, but the reason to move a pin from `v0.2.0a1` to `v0.2.0a2` is
the Diffrax JIT cache fix.

## Headline: Diffrax `run()` hits the JIT cache

`CompiledModel.run` goes through Diffrax's `@eqx.filter_jit` `diffeqsolve`.
Before this release, every call rebuilt:

1. `ODETerm(vf)` with a fresh Python `vf` closure
2. `SubSaveAt(..., fn=...)` with a fresh save callback per group

Those callables are static leaves for equinox and are keyed by **identity**, so
each `run()` looked like a different program and the whole solve was traced
again. Save callbacks also closed over prepared parameters, so even a stable
function object would have recompiled on every parameter draw.

**What changed** (`fix/diffrax-run-jit-cache`, PR #13):

- Vector field and save callbacks are process-stable **equinox Modules**
  (`DiffraxVectorField`, `DiffraxSaveFn`), created once and compared by
  structural equality (model digest and save/`keep` tree).
- Prepared parameters are read from Diffrax `args`, not baked into a closure.
- Nested class definitions inside the solve path are avoided (a fresh class
  object per call breaks Module equality).

**What you should see:** for a fixed save plan and solver settings, the first
`compiled.run(...)` pays compile cost; later runs with new parameter values
reuse the compiled program. The solvers example notebook
(`examples/notebooks/05-solvers.ipynb`) and the unit tests assert a large
warm/cold ratio on a small SIR Euler probe (order of 1000× on that probe).

```{admonition} Follow-up: Python floats were still static
:class: note

a2 alone was not enough when params were a plain `{str: float}` dict: equinox
treats Python floats as static leaves, so each draw still recompiled. Later
tags box those leaves to float64 arrays inside `CompiledModel.prepare` (see
`fix/prepare-box-float-params`). Until then, pass JAX arrays or wrap the solve
in an outer `@jax.jit`.
```

Calibration loops, scenario sweeps, and any host loop that calls `run()` many
times with the same structure are the intended beneficiaries.
