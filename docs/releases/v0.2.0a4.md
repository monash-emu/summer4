# summer4 0.2.0a4

**Tag:** `v0.2.0a4` · **Date:** 2026-09-22 · **Status:** alpha

This release is the **TB-port surface** on a pinnable tag. Ageing sugar,
generalised force of infection, and output algebra / `OutputSet` land together
so Kiribati and tb_macro can pin `v0.2.0a4` instead of a moving `main` SHA.

## Install

```toml
[pypi-dependencies]
summer4 = { git = "https://github.com/monash-emu/summer4.git", tag = "v0.2.0a4", extras = ["calibration", "pandas", "frames"] }
```

```bash
pip install "summer4[calibration,pandas,frames] @ git+https://github.com/monash-emu/summer4.git@v0.2.0a4"
```

See {doc}`../getting-started/installation` for extras and platforms.

## Headline: TB-port building blocks

What a tuberculosis port needs from summer4 beyond a3, now on the tag:

| Capability | How |
| --- | --- |
| Uneven age-band ageing | `TraitChain.from_breakpoints(age)` (`feat/ageing-sugar`) |
| Per-age FOI with population exponent | `ForceOfInfection(..., kind=FOIKind.GENERALISED)` (`feat/epi-generalised-foi`) |
| Infectiousness per compartment | Selector-keyed weights on the FOI (`feat/epi-compartment-infectiousness`) |
| Named output DAG | `OutputSet` over saved leaves; derived names are not re-saved (`feat/output-sets`) |
| Output arithmetic / windows | Name-aligned `Output` ops, `cumulative`, `rolling`, `integrate_intervals` (`feat/trace-algebra`) |

`Trace` is renamed to **`Output`**. Downstream code that imported `Trace` must
switch; there is no compatibility alias on this tag.

## Also in this tag

| Area | What landed |
| --- | --- |
| Rate NumPy dispatch | `np.sin(Param(...))` builds a rate node; `ndarray * rate` is one `BinOp` (see {doc}`rate-array-dispatch`) |
| Deferred callables | `defer(fn)(...)` puts ordinary Python in a flow rate without disabling hoisting |
| Custom rate nodes | Must define `__rate_bytes__` so the jit digest stays value-keyed |
| Split adjust | Bare `adjust` traits on a split bind to the destination (`fix/split-adjust-selector-side`) |
