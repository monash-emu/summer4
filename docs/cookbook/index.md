# Cookbook

Short, task-oriented recipes for modellers who already know the
{doc}`user guide <../user/index>` vocabulary. Each page answers one practical
question with working code and assertions — not a full feature tour.

Prefer the **first** recipe that solves your problem. Later recipes add power
(and ceremony) only when you need it.
