# summer4 documentation

**summer4** is a JAX-native compartmental modelling platform under active
development. This release ships the **compartment taxonomy** and a **flows
layer**: declare what the compartments are, attach named flows over selectors,
compile to a vector field, and step it with a fixed-step Euler.

```{admonition} Read this first — scope of the current release
:class: important

The public API of summer4 today is the taxonomy (`Property`, `Trait`,
`Selector`, `PropertyMap`, `Stratification`, `Groups`) plus flows
(`FlowModel`, `CompiledModel`, `TransitionFlow` / `ExitFlow` / `EntryFlow`,
`EdgeMap`, `Source` / `Dest`, rates and adjustments). `euler` returns the
**final state only** — there is no trajectory, results object or
derived-output request API.

Material from the [summer2 documentation](https://summer2.readthedocs.io) and
the [summer textbook](https://github.com/monash-emu/summer-textbook) that needs
those missing pieces is **not reproduced as working code**. It is catalogued
instead, chapter by chapter and page by page, in {doc}`evaluation/index`.
```

## Quick example

Every compartment in summer4 is a row in an integer code table. You declare the
axes, apply them (optionally to a subset), and query with a selector algebra:

```python
from summer4 import Property, PropertyMap

state = Property("state", ("S", "I", "R"))
age = Property("age", ("0-4", "5-9", "10+"))
severity = Property("severity", ("mild", "severe"))

pmap = (
    PropertyMap.from_property(state)
    .stratify(age)
    .stratify(severity, where=state["I"])
)

pmap.select(state["I"] & age["0-4"])   # int32 indices
pmap.select(severity.absent())         # compartments with no severity axis
pmap.partition(age)                    # {Trait: indices} per age band
```

See {doc}`getting-started/quickstart` for the taxonomy walkthrough and
{doc}`user/08-flows` for compiling flows over that map.

## What is missing, in one paragraph

summer4 can describe a stratified compartment space and compile named flows
over it to a JAX vector field. It cannot yet return a trajectory, a results
frame, or requested derived outputs. There is no mixing-matrix /
force-of-infection primitive, no interpolation library, and no adaptive solver
selection. `euler` is a fixed-step stepper that returns the final state only.
The consequences for documentation are quantified in
{doc}`evaluation/feature-completeness` and {doc}`evaluation/docs-coverage`.
